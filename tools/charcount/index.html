글자수는 어떻게 세나요

  • 전체 글자수: 공백과 줄바꿈을 포함한 모든 문자 수입니다. 대부분의 지원서·SNS 입력란이 이 기준을 씁니다.
  • 공백 제외: 스페이스와 줄바꿈을 뺀 순수 문자 수입니다. ‘공백 제외 800자’ 같은 조건에서 사용합니다.
  • 바이트 수: UTF-8 기준으로 한글은 3바이트, 영문·숫자·기본 문장부호는 1바이트, 이모지는 4바이트 이상입니다.
  • 단어 수: 공백으로 구분된 덩어리 수로, 영문 글쓰기 분량을 볼 때 유용합니다.

이런 데 쓸 수 있어요

  • 자기소개서·리포트의 글자수 제한 확인
  • 문자 메시지(SMS 90바이트, LMS) 분할 여부 확인
  • 메타 설명문, 게시글 제목 등 글자수 제한이 있는 텍스트 작성

❓ 자주 묻는 질문

바이트와 글자수는 무엇이 다른가요?

글자수는 문자의 개수, 바이트는 저장 공간의 크기입니다. UTF-8에서 한글 한 글자는 3바이트, 영문은 1바이트입니다. EUC-KR 환경이라면 한글은 2바이트입니다.

공백을 포함해서 세야 하나요?

공지에 별도 언급이 없으면 대개 공백 포함 기준입니다. ‘공백 제외’라고 명시된 경우에만 띄어쓰기를 뺀 수를 사용하세요.

줄바꿈도 글자수에 포함되나요?

전체 글자수에는 포함됩니다. 문서에서 복사해 붙여넣을 때 줄바꿈이 많으면 예상보다 글자수가 늘어날 수 있습니다.

입력한 텍스트가 저장되나요?

아니요. 글자수 계산은 모두 브라우저에서 처리되며 입력한 내용은 서버로 전송되지 않습니다.
