텍스트 변환 도구

텍스트를 다양한 방식으로 변환하고 처리합니다.

각 버튼이 하는 일

  • 공백 제거: 스페이스·탭·줄바꿈 등 모든 공백 문자를 없앱니다.
  • 줄바꿈 제거: 줄바꿈을 공백 한 칸으로 바꿔 여러 줄을 한 줄로 만듭니다.
  • 대문자 / 소문자: 영문 알파벳의 대소문자를 일괄 변환합니다.
  • 정렬: 각 줄의 앞뒤 공백을 제거합니다(줄 순서는 그대로).
  • 역순: 전체 글자 순서를 거꾸로 뒤집습니다.

변환 결과는 위 입력을 바꾸지 않고 아래 결과 칸에 표시되며, 복사 버튼으로 가져갈 수 있습니다.

이런 데 쓸 수 있어요

  • 엑셀·표에서 복사한 텍스트의 불필요한 줄바꿈·공백 정리
  • 코드·상수 이름을 대문자 또는 소문자로 통일
  • 문장 부호나 공백이 섞인 목록을 한 줄로 합치기

❓ 자주 묻는 질문

변환이 즉시 적용되나요?

아니요. 원하는 변환 버튼을 눌러야 결과가 갱신됩니다. 여러 변환을 이어서 적용하려면 결과를 다시 입력란에 붙여넣고 다음 버튼을 누르세요.

한글에도 대문자·소문자가 적용되나요?

아니요. 대소문자는 영문 알파벳에만 적용되며 한글·숫자·기호는 그대로 유지됩니다.

입력한 텍스트가 저장되나요?

아니요. 모든 변환은 브라우저에서 처리되며 입력한 내용은 서버로 전송되지 않습니다.

🔗 관련 도구

글자수/바이트 계산기

텍스트의 글자수, 공백 포함/제외 글자수, 바이트 수를 계산합니다.

단위 변환기

길이, 무게, 온도, 면적, 부피, 시간, 데이터 용량을 변환합니다.

카메라 셔터카운트 확인기

사진의 EXIF 정보를 브라우저에서 분석합니다.
