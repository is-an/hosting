# Project Instructions

## Project Goal

This is a utility website designed for search traffic and monetization.

Current features:
- D-Day calculator
- Lotto number generator

Future features:
- Various calculators
- Utility tools
- Mini games

## Tech Stack

- HTML
- CSS
- Vanilla JavaScript
- GitHub Pages
- No unnecessary frameworks

## Project Structure

- index.html: main page
- assets/style.css: global styles
- assets/app.js: shared JavaScript and existing functionality
- assets/i18n.js: multilingual system

## Important Rules

1. Do not delete existing functionality.
2. Do not change existing calculation logic unless explicitly requested.
3. Preserve existing URLs.
4. Keep GitHub Pages compatibility.
5. Do not introduce unnecessary dependencies.
6. Reuse existing CSS and JavaScript before creating new files.
7. Keep common UI consistent across pages.
8. SEO must be considered for every new page.
9. Mobile responsive design is required.
10. AdSense-related code must not be removed or modified unnecessarily.
11. Do not modify ads.txt unless explicitly requested.
12. Do not modify robots.txt or sitemap.xml unless explicitly requested.
13. New tools should have their own clear structure.
14. Avoid duplicating common CSS.
15. Avoid duplicating common JavaScript.
16. Code should remain simple and maintainable.

## SEO

Every new tool page should consider:

- unique title
- unique meta description
- one clear H1
- useful explanatory content
- FAQ where appropriate
- internal links
- canonical URL
- mobile usability

Do not create thin pages containing only a calculator.

## Dark Mode

Dark mode must use the existing global CSS system.

Do not create separate duplicated dark-mode CSS for individual pages.

## Multilingual

Supported languages:

- Korean
- English
- Chinese
- Japanese

Translations should be managed through:

assets/i18n.js

Do not duplicate translation logic across pages.

## Before modifying code

First inspect the existing project structure and code.

Do not rewrite files unnecessarily.

Make the smallest change necessary to complete the requested task.

After changes, check that existing functionality still works.
