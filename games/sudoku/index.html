MINI GAME

스도쿠

난이도를 선택하고 새로운 9x9 퍼즐을 완성하세요.

시간 00:00 · 실수 0

게임 방법

빈 칸을 선택한 뒤 아래 숫자 버튼 또는 키보드 숫자를 입력하세요. 같은 숫자는 강조되고, 틀린 답은 표시됩니다.

스도쿠 규칙

9×9 칸을 1~9 숫자로 채우되, 각 가로줄·세로줄·굵은 선으로 나뉜 3×3 상자 안에서 같은 숫자가 두 번 나오면 안 됩니다. 처음 주어진 숫자만으로 나머지 칸이 하나의 답으로 결정됩니다.

풀이 팁

  • 숫자가 많이 채워진 줄·상자부터 보면서 들어갈 수 있는 칸이 하나뿐인 숫자를 찾습니다.
  • 한 칸에 들어갈 후보가 둘뿐이면 연필로 적듯 기억해 두고 다른 칸을 먼저 풉니다.
  • 난이도가 높을수록 처음 주어지는 숫자가 적어 후보를 좁히는 과정이 길어집니다.

자주 묻는 질문
